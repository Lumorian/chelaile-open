# 合规、伦理与免责

> 本文不是法律意见。它只是把本项目**做了什么、没做什么、边界在哪**写清楚，供使用者自行判断。

## 1. 项目性质

本项目是一个**互操作性实现**（interoperability implementation）：

- 目的是让用户能以自己选择的方式（浏览器、终端、自建服务）阅读**公开的公交到站信息**；
- 代码全部为独立重写，**不包含**原 App 的反编译产物、不包含 Dex、不包含 `libDexHelper.so` 或任何加固壳代码；
- 仓库中唯一来自上游的二进制是 `tests/fixtures/station-detail.encrypted.json`——一段 7.5 KB 的**加密响应样本**，用于回归测试解密逻辑，不含任何个人信息；
- 不修改、不重打包、不二次分发原 APK；`work/app.apk`、`out/`、`tools/` 均在 `.gitignore` 中。

## 2. 我们主动放弃的能力

逆向过程中确认了以下接口存在，但**没有实现**，也不接受相关 PR：

| 能力 | 原因 |
| --- | --- |
| 账号登录 / 手机号绑定（`/wow/user!login2.action`、`bind2`、`bindPhone`） | 涉及个人身份信息，超出“看公交”的必要范围 |
| 支付（`/buspay/checkOpen`、`h5-paycode`） | 金融相关，风险与收益完全不成比例 |
| 广告相关（`/adpub/adv!closeAd.action`、`getTabActivities`） | 屏蔽广告不是本项目目标；本项目只是**不请求**广告位 |
| 打卡 / 积分 / 能量（`energy` 页） | 属于账号激励体系 |
| 任何形式的刷量、伪造上报、批量注册 | 明显的滥用 |
| 绕过付费或会员内容 | 本项目不认为上游有付费墙，也不尝试寻找 |

## 3. 请求行为约束

代码层面已经做到：

- BFF 对上游请求设置 12 秒超时、最多 2 次重试、指数退避；
- 到站类接口缓存 15 秒并**合并并发请求**，一个前端页面 7 个组件同时挂载只会打一次上游；
- 城市线路表缓存 30 分钟（北京单城 1.5 MB，不缓存等于对上游做压测）；
- 不并发爬取、不遍历城市、不做全量镜像。

使用者应当：

- 只查询自己真正要看的线路与站点；
- 不要把它部署成公共高流量服务；
- 不要移除或缩短缓存 TTL 去“追求实时”。

## 4. 法律风险提示（按司法辖区）

- **中国**：《著作权法》保护计算机程序；《反不正当竞争法》第十二条涉及妨碍、破坏他人网络产品正常运行。**为 interoperability 而分析公开协议**在多数司法实践中被视为合理使用的边缘地带，但**复制代码、破解加密保护、绕过技术措施**风险显著更高。本项目不复制代码、不破解 DRM（App 未对数据接口设访问控制，仅做了传输层加密，密钥内置在客户端）。
- **美国**：DMCA §1201 禁止规避“有效控制访问”的技术措施；但 §1201(f) 有 interoperability 例外（仅限独立开发的程序之间）。**逆向工程本身**在 `Sega v. Accolade`、`Google v. Oracle` 之后有较大空间，但**契约条款**（ToS）可能另行限制。
- **欧盟**：Software Directive 2009/24/EC 第 6 条允许为 interoperability 而反编译，且不得用于侵权目的。

无论辖区如何，**署名、非商业、不替代原产品**都是降低风险的有效做法。

## 6. 隐私

- 本项目**没有**服务端账号、**没有**数据库、**没有**日志上报；
- BFF 默认只打印 `method path 耗时`，**不记录 query 参数**（其中含坐标）；
- 前端坐标仅存 `localStorage`，不上传除上游协议要求之外的任何地方；
- 演示模式完全离线，适合截图与录屏；
- 上游会给匿名 `userId=browser_xxx`，本项目在本地随机生成，与设备信息无关。
